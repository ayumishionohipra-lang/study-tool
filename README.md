# 学習アプリ（study tool）

子ども向けの学習アプリです。計算（足し算・引き算・掛け算・割り算・九九・ひっ算）、漢字クイズ、英単語、教科書問題の自動生成などができます。

## 📌 このREADMEの目的

このアプリを **GitHub Pages** で公開すると、以下のメリットがあります。

- **毎回同じURL**でアプリを開けるので、進捗データ（レベル・バッジ・保存した問題など）が**ちゃんと引き継がれます**（ファイルをダウンロードし直すたびにデータが消える問題がなくなります）
- ブックマークしておけば、パソコン・スマホ・タブレットどこからでも同じアプリ・同じデータにアクセスできます（同じブラウザでログインしている場合。データ自体はブラウザのlocalStorageに保存されるため、**ブラウザが変わるとデータは共有されません**）
- 無料で公開できます（GitHub Pagesは無料の静的サイトホスティングサービスです）

## 🚀 公開手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成する（例：`study-tool`）
2. このフォルダの中身（`index.html` と `README.md`）をリポジトリにアップロードする
   - GitHubのウェブ画面から「Add file」→「Upload files」でドラッグ＆ドロップでもOK
3. リポジトリの「Settings」→「Pages」を開く
4. 「Source」で `main` ブランチ（または `master`）、フォルダは `/ (root)` を選んで「Save」
5. 数分待つと、`https://（あなたのユーザー名）.github.io/study-tool/` のようなURLが発行される
6. そのURLをブックマークして、毎回そこからアプリを開く

## ⚙️ AI機能（教科書から問題自動生成・英単語登録）について

このアプリの一部機能（お母さんモードの「教科書から問題を自動生成」「英単語を登録」）は、AnthropicのClaude APIを直接呼び出す仕組みになっています。

- GitHub Pagesのような**静的サイト**では、サーバー側の処理ができないため、この機能を使うには**ご自身のAnthropic APIキー**が必要です
- アプリ内の「お母さんモード」→「⚙️ AI機能の設定」からAPIキーを登録してください（[console.anthropic.com](https://console.anthropic.com/settings/keys) で取得できます）
- 使った分だけ課金される仕組みで、1回の問題生成はだいたい数円〜数十円程度です
- キーはブラウザにのみ保存され、外部には送信されません。**共有パソコンでは使わないでください**
- 課金したくない場合は、無料の代替方法として、Claudeとのチャットで直接問題を作ってもらい、アプリの「💚 無料」カードに貼り付けて保存する方法もあります（アプリ内に説明があります）

## 💾 データについて

- 進捗データ・保存した問題は、すべてブラウザの localStorage に保存されます（サーバーには送信されません）
- 「お母さんモード」→「💾 データのバックアップ」から、いつでもデータをファイルとして書き出し・読み込みができます
- 大事なデータなので、定期的にバックアップを取り、Google Driveなど別の場所にも保存しておくことをおすすめします

## 📂 ファイル構成

- `index.html` — アプリ本体（このファイルだけで動作します）
- `README.md` — このファイル

## 🔒 プライバシー

- 子どもの学習データは、すべてこのアプリを開いているブラウザの中だけに保存されます
- GitHub Pagesで公開しても、それは「誰でもこのアプリの画面を開ける」という意味で、**データそのものが公開されるわけではありません**（データは各ユーザーのブラウザに個別に保存されます）
- ただし、リポジトリを Public（公開）にすると、アプリのソースコード自体は誰でも見られる状態になります。気になる場合はリポジトリを Private に設定してください（Private リポジトリでも GitHub Pages は使えますが、無料プランでは一部制限がある場合があるので、GitHubの最新情報をご確認ください）
